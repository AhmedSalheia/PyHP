# v0.3.0: Ecosystem and data fidelity (released 2026-11-08)

Decisions: Composer packages declare Python requirements in their own `extra.pyhp`; the root project can tighten versions, ignore a package's requirements (`extra.pyhp.ignore-packages`) and override versions (`extra.pyhp.overrides`, uv only); `pyhp lock` writes `pyhp.lock` (cross-platform with uv); the starter lives in its own repository, `pyhp-php/starter`.

## Done
- [x] Real-world `pyhp setup` tests in CI: Linux, Windows, macOS × uv / system Python (PR #27)
- [x] Lossless numbers: integer-like Python numbers become PHP `int` when they fit in 64 bits (PR #28)
- [x] Python requirements from installed Composer packages, root control and conflict reports (PR #29)
- [x] `pyhp lock`, `pyhp.lock` and `pyhp setup --exact`, smoke test extended (PR #30)
- [x] Starter project `pyhp-php/starter` (built and tested; published after this release)
- [x] Docs, CHANGELOG and release 0.3.0
